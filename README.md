## Project

VoteSphere is a client-side academic Online Voting System demo for student elections.

It provides:
- Login and signup
- Role-based Admin and Voter modules
- Election creation and activation/closing
- Candidate management
- Registered voter list
- One-vote-per-election prevention
- Vote confirmation modal
- Live result display
- Local Storage persistence
- Responsive CSS Grid + Flexbox interface

## How to run

1. Keep all four files in the same folder.
2. Open `index.html` in a modern browser.
3. Login with the Admin or Voter demo account.
4. As Admin, create/activate elections and add candidates.
5. As Voter, select a candidate and submit the ballot.
6. Use the status and results sections to review the vote.

## Important academic note

This is a **client-side academic demonstration**, not a production-grade election system. User accounts, sessions, elections, candidates and votes are stored in the browser's Local Storage. It should not be described as secure election infrastructure.
